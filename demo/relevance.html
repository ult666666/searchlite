      How to read this

      • P@5 divides relevant hits by 5, counting empty slots. R@10 and nDCG@10 use the top 10. MRR and MAP use the whole ranking, up to 100 results. nDCG uses the grade as the gain, discounted by log₂(rank + 1).
      • Grades: 3 answers the query directly, 2 is substantially relevant, 1 is partly relevant and 0 is not relevant. Documents without a judgment count as grade 0.
      • The configurations were fixed before the evaluation was run. With 22 queries, one query can account for a whole difference, so treat small changes as noise.
      • The toy hybrid vectors are hashed character trigrams. They capture spelling overlap, not meaning, and no model or external service is called.
      • Queries run as written, without the search demo’s prefix match on the last word. BM25F scores compare only within one query and configuration, and RRF scores use a different scale.
      • The JSON download records the inputs and results so a run can be reproduced. The page stores nothing in the browser.
